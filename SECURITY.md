# Seguridad

## Reportar una vulnerabilidad

Usa [Report a vulnerability](https://github.com/erikwco/projectory/security/advisories/new) para enviar un reporte privado al mantenedor. Si GitHub todavía no ofrece esa opción, abre un issue solicitando un canal privado, sin incluir detalles de la vulnerabilidad.

No publiques credenciales, catálogos SQLite, rutas personales ni instrucciones de explotación en issues públicos. Incluye en el reporte privado la versión o el commit afectado, el impacto esperado y los pasos para reproducirlo con datos ficticios.

## Versiones

Projectory está en desarrollo. Las correcciones se aplican a `main`; todavía no hay versiones estables con mantenimiento separado.

## Datos locales

El catálogo guarda nombres, rutas, descripciones, tags y datos de Git en tu equipo. Revisa y anonimiza capturas, respaldos y salidas JSON antes de compartirlos. `pt info` muestra la ruta del catálogo utilizado.
